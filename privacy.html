這份政策涵蓋什麼

這份政策說明 Kitchen Multi Timer iOS V1 App，以及這個官方網站如何處理資料。

裝置內的資料

下列資料存在你的裝置內的 SQLite 資料庫。V1 不需要帳號，沒有開發者提供的雲端同步服務，也沒有把計時資料傳送到開發者伺服器的功能。

  • 計時範本及自訂名稱
  • 計時時間、狀態與截止時間
  • 首頁快捷及排序
  • 顏色與提示音設定
  • App 偏好設定與語言
  • 額度紀錄，以及已刪除內建項目的識別紀錄

本機通知

  • 計時完成提醒使用裝置上的本機通知。
  • 通知內容可能包含你設定的計時名稱。
  • 通知由裝置排程，不使用開發者的推播伺服器。
  • 通知是否顯示、是否發聲，以及通知權限，由 iOS 控制。

Google Mobile Ads SDK

  • V1 iOS App 安裝包包含 Google Mobile Ads SDK，以及其附帶的 User Messaging Platform 元件。
  • V1 正式版不主動初始化 Google Mobile Ads SDK。
  • V1 正式版不建立或發送 Banner、Rewarded 廣告請求，也不顯示廣告。
  • V1 沒有主動請求 App Tracking Transparency 追蹤許可。
  • Google SDK 的隱私權資訊聲明說明，在提供相關服務時可能涉及裝置識別碼、粗略位置、廣告互動及診斷等資料。這是該 SDK 對其服務的宣告，不是本政策對 V1 已實際蒐集這些資料的陳述。
  • 目前尚未透過網路流量實測確認未初始化 SDK 的全部網路行為。本政策不宣稱該 SDK 絕對不會連線或蒐集資料，也不宣稱 V1 已經把個人資料傳給 Google。
  • 未來版本若啟用廣告功能，會先重新檢視並更新這份隱私權政策。

刪除與備份

  • 你可以在 App 內刪除可管理的範本、計時與其他項目。
  • 基本額度內可以管理 0 到 2 個首頁快捷，以及 0 到 4 個計時範本。快捷可以新增、移除與重新排序。刪除已設為快捷的範本時，會先解除快捷再刪除。已經啟動的計時不受範本刪除影響。
  • 刪除 App 會移除裝置上的 App 容器及其中的本機資料。
  • iOS 的 iCloud 或電腦備份可能包含 App 資料，並在還原備份時把這些資料恢復到裝置上。
  • 開發者不提供獨立的伺服器資料保存，也不提供帳號刪除服務。

這個網站

  • 這個網站由 GitHub Pages 提供。
  • 網站沒有整合 Analytics 或廣告追蹤 script，也讀不到 App 裡的計時資料。
  • 你若選擇語言，這個選擇存在瀏覽器的 localStorage，鍵名是 kitchen-multi-timer-language，值只會是 zh-Hant、en 或 ja，用來在下次開啟時沿用同一種語言。
  • GitHub 作為網站託管服務提供者，可能依其政策處理必要的網站存取與技術資訊。本政策不記載 GitHub 日誌的保存期限。

政策變更

App 或這個網站如果改變儲存或傳送資料的方式，本頁會一併更新。未來版本啟用廣告功能之前，會重新檢視並更新相關說明。
